# 💬 Creator Chat Moderation — Official Recruitment Portal

An interactive, mobile-responsive recruitment and candidate onboarding web portal for **Full-Time Creator Chat Moderators**, built with a custom **Dark Liquid Glassmorphism** UI and deployed via **GitHub Pages**.

---

## ✨ Key Features

- **🔞 18+ Age Verification Gate (`index.html`)**
  - Mandatory session-persisted age verification before accessing the portal.
  - Animated 3D liquid glass visuals and live creator chat moderation previews.
- **📄 Comprehensive Role & Compensation Breakdown (`details.html`)**
  - Clear role overview, adult platform content disclaimer, core responsibilities, tiered commission rates (**35% – 50%**), and monthly payout details (**GCash, PayMaya, BPI**).
- **🎓 6-Day Training Process (`training.html`)**
  - Transparent breakdown of training duration, daily hours, cohort schedules, Day 5 evaluation, and Core Team contract execution.
- **🚀 Secure Candidate Application Form (`apply.html`)**
  - Interactive client-side form with live preview (`Name`, `Age`, `Country/Location`, `Gender`, `Working/studying?`) and a locked referral tag (`@noturuser12`).
  - One-click **Copy Form** and step-by-step **HR Submission Instructions** (`@Marilag_18`) with screenshot verification.
- **🔒 Zero-Backend Security & High Scalability**
  - 100% static HTML5, CSS3, and vanilla JavaScript — zero external tracking or server-side data storage, capable of handling 10,000+ visitors seamlessly on GitHub Pages CDN.

## 🚀 Deploying to GitHub Pages

1. Create a new repository on GitHub and upload `index.html`, `details.html`, `training.html`, `apply.html`, `qr.webp`, and `README.md`.
2. Navigate to **Settings → Pages** in your GitHub repository.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Select the **`main`** branch and **`/ (root)`** folder, then click **Save**.
5. Your recruitment portal will be live at `https://<your-username>.github.io/<repository-name>/`.
